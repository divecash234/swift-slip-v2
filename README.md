# Swift Slip V2

Mobile-first foundation for Swift Slip.

## Current stage

This version intentionally follows the simplicity of the original Dad's Helper mobile experience:

- Receipt / Invoice / Quote tabs
- Large touch-friendly controls
- Collapsible business details
- Fixed bottom navigation
- Customers
- Stock
- Recent documents

## Build order

1. Working document editor
2. PDF generation
3. Authentication and business accounts
4. MySQL cloud database
5. Customers and inventory persistence
6. Reports
7. WhatsApp sharing
8. Paystack subscriptions
9. Security, backups and production hardening

The original V1 deployment is separate and must not be modified.

No private backup values or credentials are stored in this repository.
